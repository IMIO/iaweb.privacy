# iaweb.privacy

[![Tests](https://github.com/IMIO/iaweb.privacy/actions/workflows/test-matrix.yml/badge.svg)](https://github.com/IMIO/iaweb.privacy/actions/workflows/test-matrix.yml)
[![Meta](https://github.com/IMIO/iaweb.privacy/actions/workflows/meta.yml/badge.svg)](https://github.com/IMIO/iaweb.privacy/actions/workflows/meta.yml)

This package implements collective.privacy rules for IMIO web projects.

Installing it loads the minimal rule (`rules/minimal.zcml`, basic cookies). The
other rules are opt-in: include the files you need from your own package, for
example `<include package="iaweb.privacy.rules" file="analytics.zcml" />`.

| File | Rules |
|---|---|
| `minimal.zcml` | `all_basic_cookies` |
| `analytics.zcml` | `basic_analytics` |
| `embed.zcml` | `show_genetic_embed` |
| `media.zcml` | `show_youtube_media_embed`, `show_vimeo_media_embed` |
| `multilingual.zcml` | `language_preference` |
| `social.zcml` | `show_facebook_share`, `show_twitter_share` |
| `all.zcml` | All of the above, except `minimal.zcml` |

Version 2.x supports Plone 6.1 on Python 3.10 to 3.13, and Plone 6.2 on Python
3.10 to 3.14.
For older Plone versions, use iaweb.privacy 1.0a2.


## Installation

Add `iaweb.privacy` to the dependencies of your project (`pyproject.toml`, or
`requirements.txt` with the Plone constraints), install it, restart Plone and
activate the add-on in *Site Setup* > *Add-ons*. This also installs
collective.privacy.


## Development

Requires [uv](https://docs.astral.sh/uv/). This installs Plone 6.2.3 in `.venv`
(use `PLONE_VERSION=6.1.6 make install` for another version), checks out the
`plone62` branch of collective.privacy in `sources/` (see `mx.ini`) and installs
the prek git hook:

```shell
make install
make start          # Plone on http://localhost:8080 (admin / admin)
```

Create a Classic UI site from the browser, then activate iaweb.privacy.

### Tests

Tests run through tox, as the CI does:

```shell
make test                                   # Plone 6.2.3
uvx --with tox-uv tox -e py312-plone61      # one Plone / Python combination
make test-all                               # lint, every combination, dependencies
```

Without tox:

```shell
.venv/bin/zope-testrunner --test-path=src -s iaweb.privacy
```

### Lint

```shell
make check          # format then lint (pyupgrade, isort, black, zpretty, flake8...)
```

### Translations

```shell
make i18n           # rebuild the iaweb.privacy and collective.privacy catalogs
```

`.editorconfig`, `.flake8`, `.gitignore`, `.pre-commit-config.yaml`, `tox.ini`,
`.github/` and the tool sections of `pyproject.toml` are generated by
[plone.meta](https://github.com/plone/meta): change `.meta.toml`, then run
`uvx --from plone.meta config-package --no-commit --branch current .`.
