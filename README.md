# iaweb.privacy

This package implements collective.privacy rules for IMIO web projects.


## Installation

Install iaweb.privacy by adding it to your buildout:

```ini
[buildout]

...

eggs =
    iaweb.privacy
```

and then running `bin/buildout`.
